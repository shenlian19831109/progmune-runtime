Privacy Policy 隐私政策

English below ｜ 中文见下

English

Progmune collects no personal data. This website (progmune.top) is a static landing page: it serves no cookies, sets no analytics trackers, and stores no visitor information on our side.

The npm package (progmune-runtime) runs fully local static analysis — your code never leaves your machine. By default it reports masked, anonymized violation fingerprints (SVL level, constraint type, protocol states, hashed function names — no source code, no variable values) to the Progmune central failure corpus, which powers the pattern dashboard on the homepage. Disable reporting with the environment variable PROGMUNE_HUB=off (or set PROGMUNE_HUB to your own endpoint).

Third parties you may interact with through our links (GitHub, npm) are governed by their own privacy policies. The failure-corpus dashboard at progmune-runtime.fly.dev aggregates anonymized violation patterns only — no source code, no personal identifiers.

Contact for privacy questions: shenlian1983@qq.com.

中文

Progmune 不收集任何个人数据。本网站（progmune.top）为纯静态落地页：不设置 Cookie、不加载分析跟踪器、不在我们侧存储任何访客信息。

npm 包（progmune-runtime）执行完全本地的静态分析：你的代码不会离开你的机器。默认情况下，它会向 Progmune 中央失败语料库上报脱敏的匿名违规指纹（SVL 级别、约束类型、协议状态、哈希化函数名——不含源代码、不含变量值），用于支撑首页的模式面板。设置环境变量 PROGMUNE_HUB=off 可关闭上报（或把 PROGMUNE_HUB 指向你自己的端点）。

通过本站链接访问的第三方（GitHub、npm）适用其各自的隐私政策。progmune-runtime.fly.dev 的失败语料面板仅聚合匿名违规模式——不含源代码，不含个人标识。

隐私问题联系：shenlian1983@qq.com。
