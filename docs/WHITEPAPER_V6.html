2. 问题与市场 Problem & Market

2.1 核心问题 · The Core Problem

AI 代码生成器（Claude、GPT、Copilot、Cursor）以史无前例的速度产出语法正确的代码。但语法正确 ≠ 安全。

AI code generators produce syntactically correct code at unprecedented speed. But syntax is not safety.

当 AI 生成代码时，它可能：

  • 跳过认证步骤直接访问敏感数据
  • 分配资源后从不释放
  • 关闭连接但未失效会话
  • 提交事务但未检查授权

These are protocol lifecycle violations — invisible to every existing security tool.

2.2 市场空白 · Market Gap

工具类型能检测不能检测
SAST (CodeQL, Semgrep)代码模式、数据流、已知CVE协议生命周期违规

5.5 Knowledge Evolution — TLS 案例

❌ v0.1.0  REJECTED   (2026-06-25)  SSG auto-discovery, 27 FP, F1=46%
    Decision: benchmark. Reason: Precision=34% too low for governance.
    Evidence: curl 85 labeled seqs · FP Taxonomy: 100% state inference noise

✅ v0.5.0  APPROVED   (2026-06-26)  Resource Lifecycle, FP→8 (-74%), F1=51%
    Decision: benchmark. Reason: P=58%, acceptable for dev. R=46% trade-off.

✅ v0.9.0  APPROVED   (2026-06-26)  Repo-agnostic patterns. nginx confirmed.
    Decision: cross_repo_validation. Reason: 2-repo validation achieved.

✅ v1.0.0  APPROVED   (2026-06-28)  STABLE — 7 SSL backends, RFC 8446
    Decision: cross_repo_validation. Reason: OpenSSL verified. Production ready.

这为什么是护城河 · Why This Is The Moat

竞争对手可以复制 TLS Rule。但无法复制为什么 TLS 从 v0.1 变成 v1.0——包括每次升级的决策链、基准数据、证据来源和版本演化历史。

Competitors can copy the TLS Rule. They cannot copy why TLS became v1.0 — the complete decision chain, benchmark data, evidence sources, and version evolution history.

7. Runtime API 运行时 API

Stable Public API · 稳定公共接口（永不变更）

import { verify, explain, fix, RUNTIME_VERSION } from "@progmune/sdk"

const r = verify("./src/server.ts")
// → { runtimeVersion:"1.0.0", decision:"BLOCK", certificate, knowledge, evidence, risk }

console.log(explain(r))
// → Decision: BLOCK
// → Risk: Missing Finished (Critical, 91% confidence, RFC 8446)
// → Verified against: TLS Handshake v1.0.0, SSH v1.0.0, HTTP v1.0.0

const patch = fix(r)  // AI repair — Runtime 2.0

VerificationResult — Runtime IR

所有消费者（CLI, CI, IDE, Dashboard, LLM）都消费同一个对象。内部 Knowledge 可以任意演化，公共接口保持稳定。

All consumers depend on the same IR. Internal Knowledge evolves freely underneath.

9. 竞争力与护城河 Competitive Moat

★★★★★ Knowledge Evolution 知识演化

不可复制。TLS v0.1→v0.5→v0.9→v1.0 的完整决策链——为什么 rejected、为什么 approved、基于什么证据、谁决定的。竞争对手可以复制 TLS Rule，但无法复制为什么变成 v1.0。

★★★★★ Evidence Network 证据网络

7 仓库、700+ 序列。每新增一个验证仓库，整个知识库的置信度都在提升。网络效应——增加覆盖面使所有已有资产更可信。

★★★★★ Decision Chain 决策链

Evidence → Knowledge → Decision → Policy → Certificate。完整的审计追溯链。其他产品只报告"发现问题"，Progmune 回答"为什么判定、依据是什么、谁批准、什么时候升级"。

★★★★ Ontology 本体

Protocol Concepts with RFC references, relations, constraints. 长期壁垒——随着知识图谱增长，竞争对手的规则越来越难以匹敌。

11. 市场策略 Market Strategy

11.1 定位策略 · Positioning

不与 CodeQL 竞争。在 CodeQL 的盲区建立新品类。

"CodeQL 检查代码有没有写错。Progmune 检查 AI 有没有跳过安全步骤。"

"CodeQL checks if code is written wrong. Progmune checks if AI skipped safety steps."

11.2 进入策略 · Go-to-Market

  1. 从合规切入，而非安全。合规预算更大、竞争更少、付费意愿更强。
  2. PLSB 作为行业标准。让市场接受"PLSB Recall/Precision"作为协议安全检测的衡量标准。
  3. MCP + GitHub Action 分发。无缝集成 Claude Code、Cursor 等 AI 编程环境。
