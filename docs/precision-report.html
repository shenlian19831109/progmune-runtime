Known Issues & Resolution

TLS-DOUBLE-FREE (Fixed v3, 2026-06-30)

Bug: SSL_free + SSL_CTX_free counted as 2 "free" calls vs 2 "new" calls → clean sequence flagged as double-free.

Fix: Per-object-type tracking — SSL_free vs SSL_new, SSL_CTX_free vs SSL_CTX_new counted separately.

Verification: Clean TLS sequence [SSL_CTX_new,SSL_new,...,SSL_free,SSL_CTX_free] → PASS. Double SSL_free still caught (Critical).

Methodology

All precision measurements use 85 hand-labeled call sequences extracted from curl's C source code (lib/ directory). Labels: 49 human-annotated + 36 auto-labeled. Detection runs against actual SSG state machine validation, not keyword matching. Reproducible via npm run precision.
