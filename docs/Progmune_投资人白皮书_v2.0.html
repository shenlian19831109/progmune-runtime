零形式化保证：AI 代码能投产？

SVL-1 符号幻觉

LLM 调用项目中根本不存在的函数。传统 linter 可部分检测，但 AI 生成的幻觉函数名往往形似真实 API。

SVL-2 类型漂移

参数数量或类型与实际签名不匹配。TypeScript 编译器能捕获部分，但无法覆盖运行时动态调用。

SVL-3 数据流污染

使用未初始化变量、引入循环引用。需要完整的数据流分析——编译器做不到跨函数追踪。

SVL-4 协议违规

最关键也最隐蔽：跳过认证直接签发 JWT、支付前未验证订单。无现有工具可检测——这是 Progmune 的核心战场。

现有方案为什么不够

方案原理根本缺陷
Linter / SAST事后静态分析已生成代码不介入生成过程；无法检测跨函数调用序列违规
RAG 上下文注入将项目上下文注入 Prompt降低但不消除幻觉；LLM 仍是唯一仲裁者；无形式化保证
提示词工程精心设计指令引导模型零合规性形式化保证；随模型更新失效
人工审查人眼逐行检查不可扩展；10x 代码产出 vs 1x 审查能力 = 审查瓶颈
ProgmuneIR 作为唯一真相源，LLM 降级为受约束提议器✅ SVL-1→4 确定性保证；从每次失败中学习

2. 方案：AI Trust Decision Engine

Progmune 将 LLM 从"代码预言机"降级为"受约束的启发式提议器"。程序的真实结构（IR）是唯一权威真相源。

核心输出：四个字段，一个决策

字段类型企业价值
Trust Score0–100量化信任度——可追踪、可比较、可审计
DecisionAPPROVED / NEEDS_REVIEW / BLOCKED直接用于 CI/CD 门禁——"能上线吗？"的答案
ConfidenceHIGH / MEDIUM / LOW / UNCERTAIN诚实告知能力边界——不假装 100%
Evidence完整 7 元组 × N每个违规都可追溯到代码行——满足 SOX/HIPAA 合规审计
"企业实际关心的是'能不能上线？'而不是'58 分还是 61 分。'Decision 是最终产品，Score 是中间变量。Critical violation → 硬 BLOCK，不受 Score 影响。"

四维信任模型

Policy Compliance 35%

企业安全/合规策略执行。6 条可配置规则：confidence、provenance、PLSB coverage、human review、fingerprint、violations。

Protocol Safety 30%

认证、授权、支付、数据完整性、Ledger 五个关键协议的安全评分。内部按严重程度扣分（Critical -40, High -20, Medium -8, Low -2）。

Verification Coverage 20%

类型检查、SSG 规则、Ledger 不变量、测试覆盖率、失败基因组匹配——衡量验证手段的覆盖程度。

Governance Integrity 15%

Hash 链完整性、Ledger 完备性、生成链连续性、审计日志完备性——验证 AI 代码供应链的完整性。

Binary Gate：可解释性

每个 violation 必须包含完整的 7 元组（rule_id, file, function, evidence, why, fix, policy_ref）。不可解释 = 不可信。若 Explainability Gate 不通过，整体 Confidence 标记为 UNCERTAIN，Decision 降一级。

3. 产品：从检测到决策

Progmune v3.0 完成了从"协议违规检测器"到"AI 信任决策引擎"的产品升级。这不是一个版本迭代——而是一次产品范式的转变。

使用场景

CI/CD 合并前门禁

在 AI 生成的 PR 合并到主分支前自动运行 Trust Check。BLOCKED → 阻止合并，NEEDS_REVIEW → 通知审查者。

平台工程统一治理

为整个组织的 AI 编码工具（Copilot、Cursor、内部 Agent）提供统一的验证层和一致的 Trust Policy。

合规审计

金融、医疗等受监管行业——Trust Report + Evidence Trail 满足 SOX/HIPAA 对 AI 生成代码的审计要求。

Agent 生产安全网

AI Agent 自动向生产环境交付代码时的最后一道防线——在部署前验证每一行 AI 代码的协议安全性。

🔒

IR 程序真相层

从源码确定性提取——不是 LLM 的"记忆"，不存在概率偏差。最底层的、不可造假的事实基础。

📐

SVL 形式化分类法

业界首个专为 AI 生成代码设计的正确性分类体系。类似 PCI-DSS 对支付安全的标准化作用。

🧠

三层免疫记忆

工作记忆 → 情景记忆 → 语义记忆。每次拦截都让系统更聪明——网络效应随时间累积。

🔌

LLM 无关架构

约束引擎是确定性规则系统。不绑定任何模型。LLM 越强，Progmune 越有价值。

🛡️

隐私优先设计

不上传代码内容、变量值、文件路径。免疫网络只交换匿名化错误指纹。
